# Problem 3: P, PI and PID control

Run `3. PID/RunPIDControl.m` in MATLAB. It uses the shared functions in
`Problem 2/Common` and compares P, PI and PID control for initial-condition
recovery and a temporary disturbance in F3.

Pairing: F1 controls h1; F2 controls h2. The script plots closed-loop
responses and pump flows and prints performance metrics.
